Run `python3 serve.py` and open http://localhost:8000. The included server supports the site's extensionless page addresses.

## Deploy

Publish this folder as a static website on Netlify. No build command or dependencies are required. `netlify.toml` sets the publish folder; Netlify supports the original extensionless links.
